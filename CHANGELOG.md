# Changelog — security-and-features branch

## Security
- Added Content-Security-Policy meta tag
- localStorage reads remain try/catch protected
- Input remains restricted to a-z / Enter / Backspace / Space

## New features implemented
1. High score persistence (localStorage)
2. Pause / resume with Spacebar
3. Auto-pause when the browser tab loses focus
4. Best score shown in HUD

More features can be layered on this branch.
